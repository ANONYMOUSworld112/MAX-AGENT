## 1. EXECUTIVE SUMMARY & SYSTEM VISION

This project transforms an AI assistant into a true **Autonomous AI Operating System (MAX OS / JARVIS SUPREME)**. It bridges the gap between fictional systems (Tony Stark's J.A.R.V.I.S., F.R.I.D.A.Y., and U.L.T.R.O.N.) and modern real-world computing.

### Key Pillars:
1. **Zero Hardcoded/Static Data**: 100% of user inputs, system controls, entity extraction, calendar/reminder persistence, weather queries, and agent routing are executed dynamically at runtime.
2. **5-Layer Persistent Memory**: Maintains continuous context regarding the operator (biometrics, coding stack, schedule, and Bayesian learned habits that dynamically evolve with every interaction).
3. **Ambient Perception & Proactive Voice**: Senses user presence via idle detection, active windows, and camera/face auth to proactively deliver greetings (*"Welcome home, Sir..."*) and hardware telemetry alerts without requiring a prompt.
4. **Simultaneous Swarm Concurrency**: Decomposes complex operational goals into DAG dependency waves and executes independent agent subtasks in parallel.

## 7. STEP-BY-STEP DIRECT IMPLEMENTATION & REPLICATION GUIDE

Anyone cloning or setting up this repository can replicate the complete system by following these exact steps:

### Step 1: Clone Repository & Enter Directory
```bash
git clone <repository_url>
cd MAX-master/max-ai/files
```

### Step 2: Install Dependencies
```bash
pip install -r requirements.txt
playwright install chromium
```

### Step 3: Configure `.env` File
Create or edit `.env`:
```env
# Google Gemini API Key
GEMINI_API_KEY=your_gemini_api_key_here

# ElevenLabs Voice API Key
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
ELEVENLABS_VOICE_ID=21m00Tcm4TlvDq8ikWAM

# Local Ollama URL
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=gemma:7b

# Server Networking
MAX_SERVER_HOST=0.0.0.0
MAX_SERVER_PORT=8000
```

### Step 4: Run the Master Bootstrap & Verification Suite
```bash
python3 run_all.py
```
*or using the shell wrapper:*
```bash
bash run_all.sh
```

### Step 5: Launch the Interactive Marvel AI Terminal Shell
```bash
python3 jarvis_terminal.py
```

### Step 6: Start FastAPI REST & WebSockets Server
```bash
python3 run_all.py --server
```
